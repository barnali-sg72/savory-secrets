The Savory Secrets recipes website is built using the following technologies:
- Python - FastAPI
- MongoDB
- React JS

Steps to build and use the app:

BACKEND
1. Create Python virtual enviroment.
2. Run the following commands to create the packages:
   -  pip install py-bcrypt
   -  pip install uvicorn
   -  pip install "fastapi[standard]"
   -  pip install bson
   -  pip install pymongo
   -  pip install motor
3. Go to backend folder.
4. Update the MongoDB URL and Database name in the .env environment file.
5. Run the python file main.py

FRONTEND
1. Go to frontend folder.
2. Run the following command:
     npm init
3. Start the npm server:
     npm start

The website can be accessed at localhost:3000
